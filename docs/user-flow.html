Auth & app structure

Two people arrive from opposite directions, and land in the same room.

An organizer creating a trip and a friend opening a shared link start on opposite sides of the auth boundary, but both pass through the exact same primitive — a Supabase magic-link email — before either one has a session. From there they merge into one shared, RLS-protected Trip Home. Inviting more people from that screen feeds back into the friend's path, closing the loop that grows the trip roster.
