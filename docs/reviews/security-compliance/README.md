# Security and compliance reviews

This folder contains point-in-time security and compliance review evidence.
Use the baselines for standing requirements and the roadmap and code for
current status and shipped behavior.

## Project reviews

[`project/`](project/) contains dated whole-project audits, follow-ups, and
verification reports.

## Feature reviews

[`features/`](features/) contains early constraints and final review reports,
grouped by the matching slug in [`../../features/`](../../features/). New security
and compliance review artifacts belong here rather than in the feature record
folder.

## Standing policies

The baselines remain at the docs root because they apply to future work:
[`../../security-baseline.md`](../../security-baseline.md) and
[`../../compliance-baseline.md`](../../compliance-baseline.md).
